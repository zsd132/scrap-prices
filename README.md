# 再生行情 · 废旧物资价格查询

一个面向打包站和回收商的废旧物资实时行情网站，覆盖废钢、废有色、废纸、废塑料等品类，按地区查询、价格排行、历史趋势一览无余。

## 线上地址

**https://zsd132.github.io/scrap-prices/**

手机、电脑浏览器直接打开，无需注册。

## 功能特性

- **地区查价**：按省/市筛选废钢、铜、铝、纸壳、塑料等各品类当日报价
- **品类细分**：25 个细分型号（光亮铜、黄板纸、PET瓶片、304不锈钢…），单位 元/吨
- **价格排行**：同一品类全国城市报价从高到低，一眼看出货套利空间
- **历史趋势**：选地区+品类，看近半年价格走势折线图
- **涨跌速览**：首页涨幅榜/跌幅榜，今天什么在涨什么在跌
- **每日自动更新**：GitHub Actions 每天定时抓取公开行情数据

## 当前数据覆盖

| 大类 | 品类数 | 覆盖地区 |
|---|---|---|
| 废钢铁 | 7 个型号 | 唐山/石家庄/沧州/邯郸/沈阳等 |

> 数据源：回收商网公开报价、Mysteel、生意社、商务部再生资源价格指数。后续持续扩充。

## 技术栈

- 纯静态 HTML + CSS + 原生 JavaScript，无需后端
- ECharts 画趋势图
- Python 爬虫抓取公开行情
- GitHub Actions 定时任务自动更新数据
- GitHub Pages 免费托管

## 本地开发

```bash
# 克隆仓库
git clone https://github.com/zsd132/scrap-prices.git
cd scrap-prices

# 安装爬虫依赖
pip install beautifulsoup4 lxml

# 抓一次最新价格
python3 scraper.py

# 本地预览
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 项目结构

```
├── index.html          # 网站主页面
├── scraper.py          # 价格爬虫
├── prices.json         # 爬虫输出的数据
└── .github/workflows/
    └── scrape.yml      # 定时抓取任务
```
